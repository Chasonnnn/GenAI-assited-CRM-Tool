## $(date +%Y-%m-%d) - Optimizing SQLAlchemy N+1 inside leased rows
**Learning:** In the `recover_expired_delivery_leases` function of `messaging_delivery_service.py`, processing leased messages sequentially resulted in multiple N+1 queries. Specifically, querying for `MessageDeliveryAttempt` and `MessageReconciliationCase` inside a loop iterating over leased rows was extremely slow. Bulk-fetching related entities using `.in_()` mapped to Python sets/dicts proved to be significantly faster without altering the underlying transaction behavior.
**Action:** When updating rows retrieved from `with_for_update`, extract the unique IDs and perform a single bulk fetch for any related models checked inside the loop. For simple existence checks, a `set()` populated via `.all()` mapped to tuples is efficient and easy to check against.
